# Сценарии и проверка требований

Связь: [EDU-2](https://vk-education-epi.youtrack.cloud/issue/EDU-2), [требования](requirements.md).
Статус: предложения для согласования. Это сценарии будущей приёмки; они не запускались на приложении, поскольку реализации пока нет.

## Пользовательские сценарии

| ID | Предусловие и действие | Ожидаемый результат | Требования |
|---|---|---|---|
| SC-01 | В каталоге есть программы; пользователь открывает каталог и выбирает программу. | Видны название, направление, аудитория, формат и статус набора; открывается страница выбранной программы. | FR-01, FR-02 |
| SC-02 | Согласованы критерии фильтрации; пользователь выбирает критерий. | Показаны соответствующие программы; для отсутствующих результатов предусмотрено понятное пустое состояние. | FR-02 |
| SC-03 | Пользователь впервые успешно входит через внешний сервис. | Создан профиль и установлена сессия; после выхода сессия больше не даёт доступа. | FR-03 |
| SC-04 | Внешний сервис входа недоступен или отклоняет вход. | Пользователь видит ошибку; успешная авторизация не имитируется. | FR-03 |
| SC-05 | Набор открыт; пользователь заполняет согласованные обязательные поля заявки. | После успешной проверки заявка сохранена для этого пользователя, программы и набора; показан результат. | FR-05, FR-06 |
| SC-06 | В обязательном поле заявки отсутствует или некорректно значение. | Ошибка указана у соответствующего поля; успешная отправка не подтверждается. | FR-05 |
| SC-07 | Набор закрыт между открытием формы и отправкой. | Сервер проверяет актуальное состояние набора и отклоняет заявку. | FR-06, BR-02 |
| SC-08 | Пользователь повторно отправляет заявку с тем же согласованным ключом уникальности. | Дополнительный дубль не создаётся; результат повторной подачи определяется согласованным правилом. | FR-06, BR-03 |
| SC-09 | Пользователь открывает личный кабинет. | Доступны его профиль и его заявки; доступ к чужим данным проверяется отдельным негативным сценарием после согласования прав. | FR-04 |
| SC-10 | Пользователь открывает информационный раздел и FAQ. | Видны утверждённые материалы об условиях участия и ответы на вопросы. | FR-08 |
| SC-11 | Пользователь отправляет обращение с корректными полями и согласием. | Обращение сохраняется; пользователь получает подтверждение. | FR-09 |
| SC-12 | Согласованы полномочия ролей; сотрудник открывает управление заявками. | Доступны разрешённые фильтры, анкеты, комментарии и CSV-экспорт. Запрещённые операции отклоняются сервером. | FR-10, FR-11 |
| SC-13 | Заблокированный сотрудник выполняет административный запрос. | Запрос отклоняется даже при обращении напрямую к серверу. | FR-10, BR-05 |
| SC-14 | Пользователь или сотрудник запрашивает переход статуса или отзыв заявки. | Сервер принимает только переходы, разрешённые согласованной схемой и правами роли. | FR-07, BR-04 |

Пустые состояния, формат сообщений об ошибках и проверки доступа к чужим данным в этой таблице — предложения к уточнению требований, а не утверждение о готовом интерфейсе.

## Согласование

- [ ] Напарник проверил соответствие документа актуальным задачам YouTrack.
- [ ] Зафиксированы результаты изучения сайта и пользовательских сценариев.
- [ ] Уточнены обязательные поля, фильтры и правила дублей.
- [ ] Утверждены роли, права, статусы заявок и разрешённые переходы.
- [ ] Согласованы предложения по качеству и измеримые показатели.
- [ ] Согласованы сценарии, ожидаемые результаты и границы первой версии.

Незаполненный пункт означает незавершённое согласование. Создание PR само по себе не закрывает EDU-2 и не переводит её в другой этап. Выполнение сценариев и реализация функций относятся к соответствующим задачам разработки и тестирования.
