# VK Education Portal

Учебный проект: симуляция разработки образовательного веб-портала, аналогичного VK Education. На текущем этапе репозиторий содержит структуру и документацию для отработки командной работы в GitHub и интеграции с YouTrack.

## Стек

Согласованные технологии: Java, Go, Node.js. Распределение по компонентам, версии и фреймворки уточняются командой.

## Структура

```text
frontend/   — клиентская часть
backend/    — серверная часть
docs/       — документация проекта
```

## Работа с репозиторием

- `main` — основная ветка; включена защита с обязательным pull request, в том числе для администраторов.
- `develop` — ветка интеграции, созданная от `main`.
- Ветки задач создаются от `develop` после согласования реальных задач с напарником.
- Номер задачи YouTrack указывается в сообщениях коммитов и названиях pull request.
- Команды изменения статуса в коммитах применяются только после согласования с напарником и проверки полей проекта.
- Релизы выполняются только по сигналу напарника.

## YouTrack

Проект: **EDU — VK Education Portal**.
Адрес: https://vk-education-epi.youtrack.cloud

Интеграция GitHub с YouTrack требует настройки и проверки. Команды запуска появятся после добавления реализации.
